# 🎬 All-in-One Social Media Video & Audio Downloader

A Telegram bot that downloads high-definition videos and MP3 audio from any social media link.

## 🌟 Supported Platforms
- **TikTok** (Watermark-free video)
- **Instagram** (Reels, Carousels, Stories, Posts)
- **YouTube** (Shorts & Full Videos)
- **X / Twitter** (Videos & GIFs)
- **Reddit** (Videos with merged audio)
- **Pinterest, Facebook, Vimeo & 1000+ sites** supported by yt-dlp

## 🛠️ Quick Setup
1. Create a bot using [@BotFather](https://t.me/BotFather) on Telegram.
2. Copy `.env.example` to `.env` and paste your `TELEGRAM_BOT_TOKEN`.
3. Double-click `run.bat` or run:
   ```bash
   python bot.py
   ```
4. Send any social media link to the bot in Telegram!
